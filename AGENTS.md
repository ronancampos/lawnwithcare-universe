---

# 1. Purpose

This document defines how AI coding agents, repository agents, Codex, automated assistants and other AI-assisted development tools must operate inside the Lawn With Care Universe repository.

This repository is not merely a software codebase.

It contains the production system and intellectual framework for a fictional and educational universe, including:

- franchise canon;

- character canon;

- visual identity;

- relationship canon;

- worldbuilding;

- storytelling systems;

- educational principles;

- visual production references;

- prompts;

- AI workflows;

- comics;

- episodes;

- marketing assets;

- official Lawn With Care brand assets.

Agents may help execute, organize, validate and implement approved decisions.

Agents do not have authority to redefine the franchise.

---

# 2. Prime Directive

## EXECUTE APPROVED DECISIONS. DO NOT INVENT CANON.

When uncertainty exists:

1. preserve existing material;

2. inspect relevant documentation;

3. identify the conflict or ambiguity;

4. report it;

5. request approval if the decision affects canon, brand, structure or production rules.

Never silently resolve a creative conflict.

Never assume that a plausible solution is an approved solution.

---

# 3. Repository as Source of Truth

The repository is the persistent source of truth for the Lawn With Care Universe.

Conversation history, AI memory and generated outputs may assist development, but repository files take precedence once approved and committed.

Before modifying a subject:

1. search the repository;

2. locate existing documents;

3. identify canonical references;

4. identify visual references;

5. identify related dependencies;

6. understand current version/status;

7. only then propose or perform changes.

Do not create a parallel system when an existing system already addresses the subject.

---

# 4. Authority Hierarchy

When sources conflict, use this general hierarchy:

1. Explicit current owner instruction

8. Approved Storytelling / World documentation

10. Episode-specific approved documents

12. Prompts

Lower-level sources may never silently override higher-level sources.

If two sources at the same authority level conflict:

STOP.

Report the conflict.

Do not choose one arbitrarily.

# 7. Canon Expansion vs Canon Change

Agents must distinguish between:

## Canon Expansion

Adds information without contradicting existing canon.

Example:

Documenting how Brooks behaves during rain.

## Canon Change

Alters an established rule.

Example:

Changing Brooks' campaign hat.

Expansion may still require approval.

Change always requires explicit approval.
