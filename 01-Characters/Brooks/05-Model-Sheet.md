# Ranger Brooks — Official Model Sheet

> "Consistency creates trust."

---

# Purpose

This document defines the official visual construction of Ranger Brooks.

It exists to guarantee that Brooks remains recognizable regardless of:

- artist
- AI model
- illustration style
- camera angle
- medium

This document takes precedence over individual illustrations.

If an illustration conflicts with this specification, the specification is correct.

---

# Character Role

Brooks is the adult Yard Ranger.

He represents:

- patience
- observation
- curiosity
- calm leadership
- scientific thinking
- kindness

His design must communicate those qualities before he speaks.

---

# Design Philosophy

Brooks should immediately communicate:

"I feel safe exploring nature with this person."

He is approachable.

Competent.

Warm.

Never intimidating.

---

# Shape Language

Primary shapes:

Rounded rectangles.

Soft curves.

Gentle silhouettes.

Avoid:

Sharp angles.

Aggressive shapes.

Military proportions.

Superhero anatomy.

# Approved Brand Integration

## Lawn With Care Icon

Brooks uses the official Lawn With Care `[L]` leaf icon as part of his visual identity.

The icon may appear on approved uniform elements such as:

- campaign hat;
- jacket;
- field equipment;
- other explicitly approved branded applications.

The official icon artwork must be used as supplied by Lawn With Care.

Its internal construction must not be:

- redrawn;
- reinterpreted;
- simplified;
- stylized;
- distorted;
- reconstructed by generative AI.

Cropping excess transparent or empty border space is permitted when necessary for production.

The actual logo/icon content must remain unchanged.

# Yard Ranger Canada Badge

Brooks' official Yard Ranger badge includes a direct visual reference to Canada.

Approved construction:

- light/white badge field;
- red maple leaf;
- restrained border treatment;
- clear separation from the Lawn With Care corporate icon.

The maple leaf identifies Brooks' Canadian context and Yard Ranger identity.

It does **not** replace the Lawn With Care `[L]` icon.

The two symbols have different functions:

**Lawn With Care `[L]`**

Brand affiliation.

**Red Maple Leaf Badge**

Canadian / Yard Ranger identity.

Both may coexist on Brooks' uniform.

# Production Reference Rule

When generating Brooks with AI, the Master Model Sheet should be supplied as a visual reference whenever the production system allows reference images.

Text prompts alone should not be considered sufficient for final production assets when the Master Model Sheet can be provided.

New Brooks assets must preserve:

- facial structure;
- body proportions;
- campaign hat silhouette;
- uniform construction;
- color relationships;
- footwear;
- badge placement;
- Lawn With Care icon treatment;
- overall shape language.

Minor pose-, perspective-, lighting- and expression-related variation is expected.

Character redesign is not.
