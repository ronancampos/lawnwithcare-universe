# Brooks Visual Canon Audit v1.0

## Purpose

This audit verifies that all current visual assets for Ranger Brooks remain consistent with the approved written canon, Master Model Sheet, brand rules and production standards.

No AI-generated element becomes canon automatically.

The purpose of this audit is to identify:

- approved visual decisions;
- inconsistencies;
- accidental AI inventions;
- assets requiring correction;
- elements requiring canon approval.

---

# Authority Hierarchy

Visual decisions must follow this order:

1. `14-Canon.md`
2. `15-Design-Rules.md`
3. `06-Wardrobe.md`
4. `05-Model-Sheet.md`
5. Official Lawn With Care Brand Assets
6. `Brooks-Master-Model-Sheet-v1.0.png`
7. Other approved Brooks asset sheets
8. Individual AI generations

Lower-level assets may not override higher-level canon.

# Official Brand Authority

Official Lawn With Care logo files are stored in:

`00-Franchise/Brand/Logos/`

These files must be used exactly as supplied.

AI-generated reproductions are not authoritative.

The logo must not be:

- redrawn;
- reconstructed;
- distorted;
- recolored;
- simplified;
- given additional leaves;
- given alternative frames;
- given different typography;
- given different spacing.

Cropping empty border space is permitted.

Internal artwork is not.

# Known AI Failure Modes

Current production has identified recurring AI errors:

## Logo drift

AI changes:

- leaf count;
- frame geometry;
- typography;
- spacing;
- colors.

Solution:

Use official Lawn With Care source assets in final artwork.

---

## Badge drift

AI changes:

- shield shape;
- circular badge;
- text;
- maple leaf size;
- border treatment.

Solution:

Use one approved badge reference and composite when necessary.

---

## Prop invention

AI frequently adds plausible objects that were never approved.

Solution:

Treat new props as proposals until canon review.

---

## Character drift

Possible changes include:

- face width;
- eye size;
- body proportions;
- hat dimensions;
- boot style.

Solution:

Always provide the Master Model Sheet as visual reference.
