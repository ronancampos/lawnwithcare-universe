# 🌱 Lawn With Care Universe

# Architecture

---

> **The Franchise Bible is a living system. Every document has a purpose, every purpose has a place, and every place has a dependency.**

---

# Purpose

The Architecture defines how the entire Lawn With Care Universe documentation is organized.

It explains:

• where information belongs

• which document is authoritative

• how future documents connect

• where new knowledge should be added

This prevents duplicated information and keeps the franchise consistent as it grows.

---

# Single Source of Truth

Every topic has exactly one authoritative document.

Example:

Brooks' eye color

Lives only in

Character Bible

Not inside prompts.

Not inside comics.

Not inside marketing.

Everything else references the Character Bible.

# Golden Rule

Whenever uncertainty exists, move upward.

If an episode conflicts with the Story Bible:

The Story Bible wins.

If the Story Bible conflicts with the Franchise DNA:

The Franchise DNA wins.

If the Franchise DNA conflicts with the Vision:

The Vision wins.

The Vision is the highest authority.
