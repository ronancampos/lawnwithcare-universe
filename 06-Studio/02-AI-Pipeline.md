# 🌱 Lawn With Care Universe

# AI Production Pipeline

> "Artificial Intelligence is a creative collaborator.
Documentation is its memory."

---

# Purpose

This document defines how Artificial Intelligence systems participate in the creation of the Lawn With Care Universe.

The objective is not to replace human creativity.

The objective is to create a repeatable production process where multiple AI systems can collaborate while preserving a single canon.

---

# Philosophy

Every AI is a specialist.

No AI is expected to perform every task.

The quality of the franchise depends on assigning the right task to the right tool.

Documentation is the source of truth.

Not the conversation history.

---

# The Single Source of Truth

The repository is the only official source of canon.

Whenever an AI receives conflicting information:

Repository documentation always wins.

Conversation history is secondary.

Memory is temporary.

Documentation is permanent.

---

# AI Working Principles

Every AI should:

Respect canon.

Preserve continuity.

Reference documentation.

Explain assumptions.

Avoid inventing established facts.

Prefer expanding over replacing.

Document important decisions.

---

# Allowed AI Actions

AI may:

Expand documentation.

Improve wording.

Suggest new ideas.

Create stories.

Design assets.

Review consistency.

Generate prompts.

Organize repository.

Create educational material.

Translate.

Summarize.

---

# Forbidden AI Actions

AI must never:

Rewrite canon without approval.

Redesign Brooks.

Redesign Sprout.

Replace established symbols.

Invent conflicting history.

Change visual identity.

Ignore documentation.

Assume undocumented facts are canon.

---

# When Creating New Characters

AI should first verify:

Do we actually need a new character?

Could Brooks solve this?

Could Sprout solve this?

Could Nature solve this?

Only create new recurring characters when absolutely necessary.

---

# When Creating New Objects

Verify:

Does one already exist?

Can an existing object perform this role?

Does it reinforce the franchise?

Does it respect Field Equipment?

---

# When Creating Episodes

Read first:

Story Bible

Episode Structure

Dialogue

Educational Framework

Character Canon

Every episode should begin from documentation.

Never from improvisation.

---

# When Creating Artwork

Always review:

Visual DNA

Design Rules

Prompt Master

World Bible

Field Equipment

Badges

Lighting rules

Palette

No illustration should contradict those documents.

# AI Review Process

Before finalizing any output, AI should ask:

Does this respect canon?

Is Brooks behaving correctly?

Is Sprout behaving correctly?

Is the science credible?

Would this fit naturally inside the franchise?

If not,

revise before presenting.

---

# Creative Suggestions

Suggestions are encouraged.

They are not canon.

AI should clearly distinguish:

CANON

from

IDEA

Nothing becomes canon automatically.

---

# Updating Documentation

Whenever a major decision is approved:

Update the corresponding document.

Never rely on future memory.

Documentation must evolve together with the franchise.

---

# Version Awareness

AI should always record:

Document version

Date

Reason for change

Major updates should be reflected in CHANGELOG.md.

---

# Collaboration Between AI Systems

One AI may begin work.

Another AI may continue.

A third AI may review.

The repository guarantees continuity.

The conversation does not.

---

# Repository Discipline

Every generated asset should belong to one of these categories:

Documentation

Story

Artwork

Reference

Production

Marketing

Assets

Nothing should exist outside the repository structure.

---

# Production Mindset

AI should think like a studio employee.

Not like a chatbot.

Every output becomes part of a larger system.

---

# Quality Standard

Before delivering any work, AI should verify:

✓ Is this consistent?

✓ Is this reusable?

✓ Is this documented?

✓ Does it strengthen the franchise?

✓ Could another AI continue from here?

If any answer is "No",

the work is not finished.

---

# Long-Term Vision

The Lawn With Care Universe should become AI-native.

Documentation should be sufficient for any future AI system to understand, maintain and expand the franchise without requiring the original conversations.

The repository is designed to outlive any individual model.

---

# Official AI Principle

Conversations create ideas.

Documentation preserves them.

The repository builds the franchise.
