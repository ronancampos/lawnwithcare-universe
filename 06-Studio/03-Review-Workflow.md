# 🌱 Lawn With Care Universe

# Review Workflow

> "Quality is not inspected into a project.
It is built through disciplined review."

---

# Purpose

This document defines the official review process for every asset produced within the Lawn With Care Universe.

The review process protects:

• Canon

• Scientific integrity

• Educational quality

• Visual consistency

• Character consistency

• Brand identity

No asset should be published without passing through this workflow.

---

# Review Philosophy

Every review asks one question:

"Does this strengthen the franchise?"

Not:

"Is it good enough?"

Every asset should make the universe stronger.

---

# Review Principles

Reviews should always be:

Objective.

Respectful.

Documented.

Constructive.

Repeatable.

Transparent.

---

# Review Pipeline

Every asset follows the same sequence.

```
Creation

↓

Self Review

↓

Technical Review

↓

Canon Review

↓

Scientific Review

↓

Educational Review

↓

Art Review

↓

Final Approval

↓

Publication
```

---

# Stage 1

Self Review

Performed by:

Creator

Purpose

Remove obvious mistakes before requesting feedback.

Checklist

Grammar

Typos

Formatting

File naming

Broken links

Version number

Metadata

---

# Stage 2

Technical Review

Purpose

Verify technical quality.

Questions

Are files correctly organized?

Are naming conventions respected?

Does the repository structure remain clean?

Are links working?

Is formatting consistent?

Deliverable

Technical approval.

---

# Stage 3

Canon Review

Purpose

Protect continuity.

Verify

Characters

Locations

Objects

Timeline

Rules

Relationships

Official terminology

Questions

Does Brooks behave like Brooks?

Does Sprout behave like Sprout?

Does this contradict another document?

Does it introduce undocumented facts?

---

# Stage 4

Scientific Review

Purpose

Protect credibility.

Checklist

Biological accuracy

Ecological accuracy

Terminology

Seasonality

Plant behavior

Animal behavior

Weather

Natural processes

If uncertainty exists,

the story should acknowledge uncertainty.

---

# Stage 5

Educational Review

Purpose

Confirm learning quality.

Questions

Does curiosity come before explanation?

Is the learning embedded in the story?

Would a child remain engaged?

Is the Discovery Challenge safe?

Does the episode encourage observation?

---

# Stage 6

Art Review

Purpose

Protect visual identity.

Checklist

Character proportions

Palette

Lighting

Expressions

Equipment

Locations

Discovery Frame™

Discovery Band™

Badges

World consistency

---

# Stage 7

Final Approval

Purpose

Evaluate the asset as part of the franchise.

Questions

Does it belong in this universe?

Does it strengthen the canon?

Would we proudly publish it?

Could it become part of future stories?

Only after this approval does the asset become official.

---

# Review Categories

Every comment should be classified.

Editorial

Scientific

Narrative

Visual

Educational

Canon

Production

Repository

This makes revisions easier to track.

---

# Severity Levels

Critical

Contradicts canon.

Must be corrected.

---

Major

Affects quality significantly.

Should be corrected before publication.

---

Minor

Small improvements.

Recommended.

---

Suggestion

Optional enhancement.

Does not block publication.

---

# Canon Protection

Any review identifying a canon conflict must:

Document the conflict.

Reference the affected document.

Suggest the appropriate correction.

Canon is never changed silently.

---

# Scientific Protection

Whenever science and storytelling conflict,

scientific integrity wins.

The story should be adapted.

Not the science.

---

# Character Protection

Every review should verify:

Brooks remains:

Patient.

Curious.

Respectful.

Never lectures.

---

Sprout remains:

Curious.

Kind.

Observant.

Never becomes an unrealistic genius.

---

# Visual Protection

Every illustration should preserve:

Silhouette

Palette

Expressions

Equipment

Lighting

Character proportions

Visual hierarchy

No redesigns without documentation updates.

---

# Documentation Review

Every new document should answer:

Is this information already documented?

Does this duplicate another file?

Should another document be updated?

Documentation should evolve,

not fragment.

---

# AI Review

AI reviewers should:

Identify inconsistencies.

Suggest improvements.

Never overwrite canon automatically.

Always explain reasoning.

Separate facts from suggestions.

---

# Human Review

Final creative responsibility always belongs to the project owner.

AI supports.

Humans decide.

---

# Review Checklist

Before publication confirm:

✓ Repository organized

✓ Naming correct

✓ Version updated

✓ Canon respected

✓ Science validated

✓ Story engaging

✓ Characters consistent

✓ Art approved

✓ Educational objective achieved

✓ Discovery Challenge reviewed

---

# Publication Gate

Nothing should be published if:

A canon conflict exists.

Scientific information is incorrect.

Character behavior is inconsistent.

Visual identity is broken.

Educational intent is unclear.

---

# Lessons Learned

Every completed project should generate:

What worked well?

What should improve?

What documentation should evolve?

Should any canon documents be updated?

This continuous improvement process keeps the franchise healthy.

---

# Official Review Principle

Reviews do not exist to find mistakes.

They exist to protect trust.

Every approved asset strengthens the universe.

Every rejected asset protects it.
