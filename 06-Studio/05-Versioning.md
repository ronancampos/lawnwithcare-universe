# 🌱 Lawn With Care Universe

# Versioning

> "Every version tells the story of how the franchise evolved."

---

# Purpose

This document defines the official versioning strategy for every document, illustration, episode and production asset in the Lawn With Care Universe.

Version history protects the creative process.

Nothing important should ever disappear.

---

# Philosophy

The repository is a living system.

Every improvement should be traceable.

Every important decision should remain documented.

History is preserved.

Not replaced.

---

# Semantic Versioning

The franchise follows Semantic Versioning.

MAJOR.MINOR.PATCH

Example

1.4.2

---

# MAJOR

Increment when:

Canon changes.

Universe rules change.

Character redesigns.

Visual identity changes.

Repository restructuring.

Examples

1.0.0 → 2.0.0

---

# MINOR

Increment when:

New sections are added.

New documentation expands existing material.

New badges.

New locations.

New tools.

Examples

1.2.0 → 1.3.0

---

# PATCH

Increment when:

Grammar corrections.

Formatting.

Broken links.

Small wording improvements.

Metadata updates.

Examples

1.2.3 → 1.2.4
