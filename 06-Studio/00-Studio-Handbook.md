# Studio Handbook

> "Great stories are not created by inspiration alone.
>
> They are built through consistent craftsmanship."

---

# Purpose

The Studio Handbook defines how the Lawn With Care Studio operates.

It documents the creative philosophy, production standards, team responsibilities and decision-making processes used to build every project.

While the Story Bible defines the fictional universe, the Studio Handbook defines the real-world workflow behind it.

This handbook is mandatory reading for everyone contributing to the franchise.

---

# Studio Mission

Create stories that help children and families rediscover the beauty of the natural world through curiosity, observation and scientific thinking.

---

# Studio Vision

Become the world's reference in educational storytelling that transforms observation into lifelong curiosity.

---

# Studio Values

Curiosity before certainty.

Craft before speed.

Quality before quantity.

Nature before spectacle.

Collaboration before ego.

Learning before perfection.

Respect before opinion.

Consistency before novelty.

---

# Our Creative Philosophy

The studio does not create products.

The studio creates experiences.

Books, comics, animations and games are only different expressions of the same philosophy.

Every project should encourage people to look more carefully at the real world.

# Canon Hierarchy

When conflicts occur, follow this order.

1. Franchise Documents

2. Character Canon

3. World Canon

4. Story Bible

5. Writer's Room Guide

6. Episode Script

7. Marketing Material

Higher-level documents always prevail.

---

# Decision Making

When evaluating ideas, ask:

Does this strengthen the franchise?

Does it respect the canon?

Does it reinforce curiosity?

Will it still feel timeless ten years from now?

If the answer is "No", reconsider.

---

# AI Collaboration Policy

Artificial Intelligence is a creative assistant.

Not a creative replacement.

AI is used to:

Generate ideas.

Draft content.

Explore alternatives.

Accelerate production.

Maintain consistency.

Humans remain responsible for:

Creative direction.

Scientific accuracy.

Narrative quality.

Final approval.

# File Naming Convention

```
00-Document-Name.md

01-Document-Name.md

02-Document-Name.md
```

Always use numerical prefixes.

Use kebab-case.

Never rename canonical documents without updating references.

# Quality Standard

Before publication ask:

Does it inspire curiosity?

Does it respect nature?

Does it remain scientifically honest?

Does it strengthen the franchise?

Would Brooks approve?

Would Sprout be proud?

If any answer is "No", revise.

---

# Knowledge Management

Every meaningful decision should be documented.

Nothing important should exist only inside conversations.

The repository is the single source of truth.

---

# Continuous Improvement

The studio evolves continuously.

Ideas are tested.

Lessons are documented.

Canon evolves deliberately.

Nothing changes without documentation.

---

# Team Culture

Everyone is encouraged to ask questions.

Everyone is encouraged to challenge ideas respectfully.

The best idea wins.

Not the loudest voice.

---

# Success Metrics

The studio measures success by:

Quality of stories.

Consistency of the universe.

Educational impact.

Reader engagement.

Long-term trust.

Not by production volume alone.

# Final Statement

Every document, illustration and episode should contribute to that mission.
